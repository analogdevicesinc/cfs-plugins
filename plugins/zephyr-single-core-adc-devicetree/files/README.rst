.. zephyr:code-sample:: adc_dt
   :name: Analog-to-Digital Converter (ADC) with devicetree
   :relevant-api: adc_interface

   Read analog inputs from ADC channels.

Overview
********

This sample demonstrates how to use the :ref:`ADC driver API <adc_api>` with
devicetree-based configuration.

Depending on the target board, it reads ADC samples from one or more channels
and prints the readings on the console. If the reference voltage is available,
the raw readings are converted to millivolts.

The ADC channel pins are board-specific. Please refer to the corresponding board
or MCU datasheet for further details.

Building and Running
********************

The ADC peripheral and pinmux are configured in the board's ``.dts`` file. Make
sure that the ADC node is enabled (``status = "okay";``).

In addition, this sample requires at least one ADC channel specified via the
``io-channels`` property of the ``zephyr,user`` node. This is typically done
using a devicetree overlay.

Example overlays provided in the ``boards`` subdirectory for MAX series boards
can be adapted for other targets as needed.

ADC channel configuration parameters (such as gain, reference, and acquisition
time) must be defined in the ADC controller child nodes. ADC resolution and
optional oversampling settings are also specified there.

See the following files for reference configurations:

- :zephyr_file:`boards/channel_adc_max32.overlay`
- Board-specific overlay files generated by System Planner (for example,
  :zephyr_file:`boards/max32690evkit_max32690_m4.overlay` for MAX32690 EV Kit).

No additional Kconfig options are required for this sample.

CodeFusion Studio
=================

Press **Pristine Build**, then **Flash** directly in the CodeFusion Studio (CFS)
tool to build and program the application.

Sample Output
=============

You should see output similar to the following, repeated every second:

.. code-block:: console

   ADC reading[0]:
   - adc@40034000, channel 0: 1587 = 484 mV
   - adc@40034000, channel 1: 2475 = 755 mV
   ADC reading[1]:
   - adc@40034000, channel 0: 2278 = 695 mV
   - adc@40034000, channel 1: 1603 = 489 mV
   ...

.. note:: If the ADC is not supported, the output will be an error message.
